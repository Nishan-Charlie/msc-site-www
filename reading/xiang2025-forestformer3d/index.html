What they did

Presents ForestFormer3D, an end-to-end framework for individual tree and semantic segmentation of forest LiDAR that combines ISA-guided query point selection, score-based block merging at inference and one-to-many association in training.

My note

Our closest application baseline: forest instance segmentation, instance-aware query selection, code and checkpoint instructions.
