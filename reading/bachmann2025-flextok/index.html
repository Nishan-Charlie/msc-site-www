FlexTok: Resampling Images into 1D Token Sequences of Flexible Length

Edit · Add comment

Roman Bachmann, Jesse Allardice, David Mizrahi, Enrico Fini, Oğuzhan Fatih Kar, Elmira Amirloo, Alaaeldin El-Nouby, Amir Zamir, Afshin Dehghan · ICML 2025 · 2025

What they did

Resamples 2D images into ordered 1D token sequences of flexible length, so the number of tokens can follow the complexity of the image.

My note

Uses ordered, variable-length representations and nested dropout. Useful inspiration for nested sampling budgets.
