FastPoint: Accelerating 3D Point Cloud Model Inference via Sample Point Distance Prediction

Edit · Add comment

Donghyun Lee, Dawoon Jeong, Jae W. Lee, Hongil Yoon · ICCV 2025 · 2025

DOI arXiv

Status

Topics

Feeds
P1 · ICCV 2027

What they did

Accelerates farthest point sampling and neighbour search by predicting how the distance between successive sample points decreases, so later samples are found without computing all pairwise distances; sampling quality and accuracy are kept.

My note

Accelerates farthest-point sampling and neighborhood operations. Helps distinguish better sampling decisions from faster sampling implementations.
