MICAS: Multi-grained In-Context Adaptive Sampling for 3D Point Cloud Processing

Edit · Add comment

Feifei Shao, Ping Liu, Zhao Wang, Yawei Luo, Hongwei Wang, Jun Xiao · CVPR 2025 · 2025

DOI arXiv

What they did

Proposes MICAS, an in-context learning framework for point cloud processing that adapts sampling at two levels: task-adaptive point sampling and query-specific prompt sampling.

My note

Combines task-adaptive point sampling and query-specific prompt selection. Relevant precedent for task-conditioned selection.
