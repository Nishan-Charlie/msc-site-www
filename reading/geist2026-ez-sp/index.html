EZ-SP: Fast and Lightweight Superpoint-Based 3D Segmentation

Edit · Add comment

Louis Geist, Loic Landrieu, Damien Robert · ICRA 2026 · 2026

DOI arXiv Code

Status
To read
Topics
backbones, budgeted-inference
Feeds
P1 · ICCV 2027

What they did

Replaces the CPU-bound partition step of superpoint pipelines with a learnable, fully GPU partition that is 13 times faster; with a lightweight superpoint classifier the whole pipeline fits in under 2 MB of GPU memory and runs in real time on multi-million-point scenes.

My note

Learns efficient GPU-based superpoint partitions. Essential reading if we pursue grouping or tokenization.
